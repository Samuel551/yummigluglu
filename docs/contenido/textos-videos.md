# Guía de Textos para Videos — Yummi Glu Glu

Referencia para agregar texto en cada clip de las recetas.
Completar junto con el editor de video (CapCut u otro).

---

## Reglas generales de estilo

| Campo        | Valor recomendado                                  |
| ------------ | -------------------------------------------------- |
| Fuente       | Bold / Heavy — fácil de leer en pantalla chica     |
| Tamaño       | Grande — visible sin expandir el video             |
| Color        | Blanco con sombra oscura, o negro con fondo blanco |
| Duración     | Aparece 0.5s después del corte, desaparece 0.5s antes del siguiente |
| Posición     | Inferior (no tapar el plato) o superior            |
| Tono         | Cálido, simple, como le hablarías a un papá/mamá   |
| Idioma       | Español neutro (sin voseo — audiencia LATAM)       |

---

## Estructura tipo por video (6 clips × 6s)

| Clip | Qué suele mostrar          | Tipo de texto                          |
| ---- | -------------------------- | -------------------------------------- |
| C1   | Plato final / presentación | Nombre de la receta + edad recomendada |
| C2   | Ingredientes juntos        | Lista corta de ingredientes            |
| C3   | Preparación paso 1         | Acción: qué se está haciendo           |
| C4   | Preparación paso 2         | Acción: qué se está haciendo           |
| C5   | Cocción o textura final    | Tip o dato útil                        |
| C6   | Bebé comiendo / plato listo | Frase de cierre + CTA                 |

---

## Template por receta

Copiar este bloque para cada receta nueva.

```
